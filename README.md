> 🧩 **Project 3 – Practicum Software Engineer Program**

**Around the World** is an interactive webpage that allows users to explore beautiful places through cards.  
It was built using **HTML**, **CSS**, and **JavaScript**, following the Practicum design brief to practice interactivity, responsive layouts, and DOM manipulation.

---

## 🧠 About the Project

This project introduced **dynamic interactivity** for the first time.  
Users can:
- Add new photo cards  
- Like/unlike their favorite places  
- Open full-size images in a modal popup  
- Edit profile information dynamically  

It’s where static HTML/CSS met **JavaScript functionality**, forming the foundation for future projects.

---

## 🛠️ Technologies Used

- 🧱 **Semantic HTML5** – clean and accessible markup  
- 🎨 **CSS3 (Flexbox + Grid)** – fully responsive layouts  
- ⚙️ **Vanilla JavaScript (ES6)** – for interactivity and DOM manipulation  
- 🧩 **BEM Methodology** – organized and readable CSS structure  
- 🖥️ **Responsive Design** – optimized for desktop and mobile

---

## 🎨 Features

✅ Add and remove image cards  
✅ Like and unlike places  
✅ Open images in a popup modal  
✅ Edit profile name and title  
✅ Form validation for better UX  
✅ Fully responsive layout

## 💡 Key Concepts Practiced

| Concept | Description |
